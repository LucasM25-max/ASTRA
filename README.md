# ASTRA

A Lit Miniature 3D world: a woodland stream runs north into a river and carries pollution with it.

Move with **WASD**, sprint with **Shift**, jump with **Space**. Click to capture the mouse.

```bash
npm install
npm run dev
```

Blender prototypes live in `blender/build_assets.py` and export to `public/models/nature.glb`. Textures are generated by `tools/gen_textures.py`.
